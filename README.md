# Maxic Admin Core ⚡

A zero-dependency, lightweight fintech & SaaS dashboard template built on native web standards. No bundlers, no npm bloat, zero framework dependencies.


![Maxic Preview](https://github.com/maxicsiva/maxic-admin-core/blob/main/01_maxic_hero_cover.jpg.png)

## Highlights

- **100% Semantic HTML5**: Runs out of the box in any browser or static host.
- **CSS Design Tokens**: Complete color, surface, and elevation variables on `:root`.
- **Flicker-Free Dark Mode**: Instant theme switching powered by a tiny inline IIFE.
- **Stack Agnostic**: Drop straight into Go, Django, Rails, Laravel, Node, or serve statically via Cloudflare Pages / Vercel.
